# Video Game Backlog Manager

## Case Study Overview
This application is built for Track A: The Fandom Vault. It is a Video Game Backlog Manager designed to help gamers track their game collection, organize items by completion status (Backlog, Playing, Finished, Dropped), and maintain a clean inventory.

## Features Implemented
- **Home Screen:** Displays the current list of logged games, handling loading states, populated lists, and empty states.
- **Detail Screen:** Provides an expanded view of a specific game's status and platform.
- **Form Screen:** Allows users to add new games to their backlog with form validation.
- **Material 3 Design:** Fully utilizes a centralized Material 3 theme with zero hard-coded colors or font sizes.

## Setup Instructions
1. Clone this repository.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter analyze` to ensure code is clean.
4. Run `flutter run` to test on a local emulator.
5. To build the release application, run `flutter build apk --release`.
